Assignment Parts & Tasks
Part 1. Basic HTML Forms
Task 0. Simple Contact Form
Created a standard contact form featuring text inputs for name, email, a message textarea, and a submit button with matching <label> elements.   


Task 1. Form with HTML5 Validation
Added built-in browser validation attributes (required, type="email", maxlength) to enforce data input rules.   


Part 2. Bootstrap Forms
Task 2. Bootstrap Form Styling
Refactored form fields using Bootstrap grid layout classes (col-md-6), placeholders, and helper text elements.   

Task 3. Bootstrap Validation Styles
Applied feedback state classes (is-valid, is-invalid) and custom error/success messaging beneath input fields.   


Part 3. Advanced Form Project
Task 4. Registration Form
Designed a complete registration form layout including first and last name inputs, email, password fields with minimum length constraints, gender radio buttons, hobby checkboxes, country select dropdown, and reset/submit buttons. Styled with Bootstrap grid and interactive feedback script.   


Summary of Work Process
Built a clean HTML5 file incorporating Bootstrap 5 CDN stylesheets and JavaScript bundles

Implemented all parts sequentially from basic inputs to advanced validated forms

Verified browser error handling and interactive Bootstrap validation scripts

Compiled execution evidence screenshots under each individual task section within this README report
